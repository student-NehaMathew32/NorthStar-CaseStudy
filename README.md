# NorthStar Urban Mobility - Data Analytics Case Study Coursework

Final year project analysing the NorthStar Urban Mobility and Logistics 
case study as part of the Databases and Analytics module.

## Repository Structure

data/
All raw CSV datasets provided for the NorthStar case study.

notebooks/
01_python_cleaning_and_analysis.ipynb — Data cleaning, quality 
analysis, and Python analytics using Pandas and NumPy.

02_sql_and_r_analysis.ipynb — SQL queries executed within R, 
statistical analysis, and data visualisation.

03_mongodb_design_and_queries.ipynb — MongoDB Atlas database 
design, implementation, CRUD operations, and query optimisation.

report/
Final submitted report in PDF format.

## Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- R (sqldf, ggplot2, dplyr)
- MongoDB Atlas + PyMongo
- Google Colab
- GitHub
